# 星屿纪年

# 第一章 灯与雾

## 1.1 雾海与灯塔

雾海之上散落着大小数百座星屿，屿与屿之间终年被浓雾封锁。主星屿北端的白色灯塔已燃烧了三百年，塔顶的灯火按古老的灯语明灭，向迷航的船只传递风暴与暗礁的消息。守护灯塔的组织称为守灯人公会，他们不隶属任何一屿的领主，只对灯语本身效忠。

## 1.2 见习守灯人

澜是守灯人公会最年轻的见习守灯人，纪元前120年生于沉钟湾边的一户渔家。她的师父乌桑是公会里资历最老的舵手，年轻时曾驾船横穿整片雾海。乌桑常说她手指稳、心也稳，是学灯语的好苗子。澜每日的工作是擦亮灯室的两百枚铜镜，并在夜里将风暴眼的暗号转译成灯语，投向雾海深处。

## 1.3 沉钟湾的传说

沉钟湾得名于湾底一口巨大的铜钟。相传纪元前300年大退潮时，海水在一夜之间退去数十里，湾底露出这口无人认得的沉钟。潮水回来之后，守灯人公会把钟留给大海，只在航图上标注：沉钟湾，夜里能听见钟响，莫循声而行。

# 第二章 潮汐氏族

## 2.1 潮汐族

潮汐族是世代生活在星屿外环礁的种族，脚趾间有蹼，能在水下闭气一炷香。他们相信海水的涨落自有意志，并将其称为潮汐术——不是操纵大海，而是听懂大海。族长叙霜是近百年来最年轻的一位，她十二岁便在风暴中驾独木舟救回七名岩居族的采石工，从此两个种族结束了长达三代人的宿怨。

## 2.2 潮汐罗盘

潮汐罗盘是潮汐族的圣物，指针不以南北为准，而以潮水的去向为准。罗盘由历代族长保管，只在雾海异常涨落时启用。纪元前120年大退潮重演的那一夜，叙霜的祖母曾携罗盘登上灯塔，与守灯人公会共同确认了退潮的边界。此后罗盘被允许存放在灯塔的灯室，象征两个种族的盟约。

## 2.3 岩居族

岩居族住在星屿内环的采石屿上，身材矮壮，擅凿岩为室。他们不习水性，船只多购自潮汐族。岩居族的首领依照传统由最年长的石匠担任，掌管内环全部采石场。虽与潮汐族有过宿怨，但自叙霜救人之事后，两族每年在沉钟湾互市一次。

# 第三章 深渊之眼

## 3.1 深渊教团

深渊教团崇拜雾海最深处的主星屿海沟，称其为深渊之眼。教团的祭司隐原是守灯人公会的抄灯员，负责誊录灯语典籍。纪元前95年，隐在一次誊录中读到被禁绝的第九章灯语，从此深信灯火的明灭是深渊的低语，遂叛出公会，在风暴眼边的孤屿上建立了第一座祭坛。

## 3.2 风暴眼

风暴眼是雾海常年不息的巨漩，海图上以一个墨圈标注。风暴眼之战爆发于405年：深渊教团信众驾十七艘祭船冲入漩涡，欲以沉钟唤醒深渊之眼。守灯人公会与潮汐族联手拦截，叙霜在乱流中折断了右桨，乌桑以灯语唤来雾海罕见的平潮，最终只有三艘祭船沉入眼底，深渊之眼没有睁开。

## 3.3 战后

风暴眼之战后，深渊教团转入地下，隐不知所踪。守灯人公会重新誊录典籍，删去了第九章灯语的所有抄本，只留灯塔顶灯的一枚铜镜背面刻着全文——那是澜亲手刻上的，她说灯语不该有被禁绝的部分，只有被看懂的部分。
